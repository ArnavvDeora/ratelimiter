# ratelimiter

Token-bucket and sliding-window rate limiters with an injectable clock, so they are testable without sleeping.

> This is a **demo project for [qi](https://myco-qi-demo.vercel.app)**, a change-quality tool
> built for the Myco engineering assessment. Its pull requests are realistic changes, some good
> and some with the kind of flaw that slips through review. The qi GitHub Action comments on
> every PR with evidence from running the tests and planting bugs in the changed lines.
